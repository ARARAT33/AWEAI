# AWEAI Overview

AWEAI is a comprehensive, terminal-native platform for AI/ASI/AGI engineering. It provides everything needed to build, train, deploy and manage AI systems at any scale.

## Core Principles

1. **No Limits** — From 1 parameter to 2T+ parameters
2. **No Dependencies** — No Hugging Face, no external AI APIs required
3. **No UI** — Pure terminal experience
4. **No Compromise** — Every tool has a real implementation

## Architecture

AWEAI is organized into modular subsystems:

- `aweai.models` — Model factory with 18+ architectures
- `aweai.scale` — Unlimited parameter training (ZeRO, FSDP, pipeline, tensor parallelism)
- `aweai.arch` — Architecture registry with 50+ neural architectures
- `aweai.cluster` — Cluster management (SSH, K8s, Slurm)
- `aweai.db` — Database layer (metadata, vector, time-series, graph, KV)
- `aweai.agi` — AGI platform (agents, memory, reasoning, planning, RSI)
- `aweai.compat` — OpenAI/Google/Anthropic API compatibility
- `aweai.hw` — Hardware abstraction layer
- `aweai.tools` — 5000+ functional tools
- `aweai.train` — Training orchestration
- `aweai.eval` — Evaluation metrics
- `aweai.export` — Model export
- `aweai.quantize` — Quantization
- `aweai.rag` — RAG engine
- `aweai.data` — Data pipelines
