# TreeOfThought

Tree of Thought (ToT) explores multiple reasoning paths as a tree for complex problem-solving.

## Usage

```python
from aweai.agi.reasoning import TreeOfThought

tot = TreeOfThought()
solution = tot.solve(problem, branching_factor=3, depth=5)
```
