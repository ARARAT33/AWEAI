# DynamicReplanner

Dynamic replanning adjusts plans in real-time based on environmental changes.

## Usage

```python
from aweai.agi.planning import DynamicReplanner

replanner = DynamicReplanner()
new_plan = replanner.replan(current_plan, new_observation)
```
