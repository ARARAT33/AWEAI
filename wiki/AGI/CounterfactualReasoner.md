# CounterfactualReasoner

Counterfactual reasoning explores "what-if" scenarios.

## Usage

```python
from aweai.agi.reasoning import CounterfactualReasoner

cr = CounterfactualReasoner()
outcome = cr.evaluate("What if I had chosen differently?")
```
