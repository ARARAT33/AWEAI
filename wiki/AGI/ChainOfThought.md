# ChainOfThought

Chain of Thought (CoT) prompting encourages step-by-step reasoning for complex problems.

## Usage

```python
from aweai.agi.reasoning import ChainOfThought

cot = ChainOfThought()
reasoning_chain = cot.reason(problem, steps=5)
```
