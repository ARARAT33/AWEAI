# CollectiveSolver

Collective solver enables groups of agents to solve problems together.

## Usage

```python
from aweai.agi.collective import CollectiveSolver

solver = CollectiveSolver(agents=[agent1, agent2, agent3])
solution = solver.solve(problem)
```
