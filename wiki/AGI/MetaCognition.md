# MetaCognition

Meta-cognition enables agents to think about their own thinking processes.

## Usage

```python
from aweai.agi.metacognition import MetaCognition

mc = MetaCognition()
reflection = mc.reflect_on_thinking(thinking_process)
improvement = mc.suggest_improvement(reflection)
```
