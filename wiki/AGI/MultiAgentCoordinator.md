# MultiAgentCoordinator

Multi-agent coordinator orchestrates multiple agents working together on complex tasks.

## Usage

```python
from aweai.agi.coordinator import MultiAgentCoordinator

coordinator = MultiAgentCoordinator(agents=[agent1, agent2, agent3])
result = coordinator.coordinate(task="Build complex system")
```
