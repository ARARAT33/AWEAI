# ConstraintSatisfier

Constraint satisfaction finds solutions that satisfy all constraints.

## Usage

```python
from aweai.agi.planning import ConstraintSatisfier

cs = ConstraintSatisfier(variables=..., constraints=...)
solution = cs.solve()
```
