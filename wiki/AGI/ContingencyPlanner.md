# ContingencyPlanner

Contingency planning creates backup plans for potential failures.

## Usage

```python
from aweai.agi.planning import ContingencyPlanner

cp = ContingencyPlanner()
contingency_plan = cp.create_backup(primary_plan, risks)
```
