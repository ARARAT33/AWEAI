# GraphOfThought

Graph of Thought (GoT) models reasoning as a graph, enabling non-linear exploration of ideas.

## Usage

```python
from aweai.agi.reasoning import GraphOfThought

got = GraphOfThought()
solution = got.solve(problem)
```
