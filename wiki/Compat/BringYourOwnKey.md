# BringYourOwnKey

Bring Your Own Key (BYOK) enables using your own API keys for cloud providers.

## Usage

```bash
# Configure BYOK
aweai providers add openai --api-key $OPENAI_API_KEY
aweai providers add anthropic --api-key $ANTHROPIC_API_KEY
aweai providers add google --api-key $GOOGLE_API_KEY
```
