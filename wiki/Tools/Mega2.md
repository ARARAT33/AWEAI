# Mega2

Mega2 tools provide extended high-level composite utilities (v3.1).

## Usage

```bash
# List mega2 tools
aweai tools list --category mega2

# Run mega2 tool
aweai tools run --name mega2_ml_pipeline --params '{}'
```
