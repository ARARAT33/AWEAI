# ResourceTier

Resource tier classification categorizes systems by computational capability.

## Tiers

| Tier | Description | Example Hardware |
|------|-------------|------------------|
| `edge` | Low-power devices | Raspberry Pi, phones |
| `pc` | Personal computers | Consumer GPUs |
| `workstation` | High-end workstations | RTX 4090, M2 Max |
| `datacenter` | Data center GPUs | A100, H100 |
| `supercomputer` | Cluster/Supercomputer | DGX, TPU pods |
