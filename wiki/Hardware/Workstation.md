# Workstation

Workstation hardware covers high-end single-user systems.

## Usage

```bash
# Check workstation hardware
aweai hardware workstation
```

```python
from aweai.hardware.workstation import WorkstationManager

wm = WorkstationManager()
info = wm.get_info()
```
