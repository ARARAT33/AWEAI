## Օգտագործման Օրինակներ

### Օրինակ 1: Բաշխված Ուսուցում AGS-ով
```python
from ai_fabric_core.algorithms import AdaptiveGradientSync
from ai_fabric_core.integrations.frameworks import PyTorchIntegration

ags = AdaptiveGradientSync(
    num_nodes=8,
    sync_strategy='adaptive',
    compression='fp16'
)

model = PyTorchIntegration.load_model('llama-7b')
trained_model = ags.train(model, dataset)
```

### Օրինակ 2: Քվանտային Ուշադրություն
```python
from ai_fabric_core.algorithms import QuantumAttention

qia = QuantumAttention(
    num_qubits=12,
    entanglement_strategy='full'
)

output = qia.forward(input_tensor)
```

### Օրինակ 3: Ֆեդերատիվ Ուսուցում
```python
from ai_fabric_core.algorithms import FederatedLearningDP

fl = FederatedLearningDP(
    num_clients=100,
    privacy_budget=1.0,
    aggregation='secure_avg'
)

global_model = fl.train(client_models)
```

### Օրինակ 4: Ինքնավերականգնում
```python
from ai_fabric_core.algorithms import SelfHealingModelSystem

shms = SelfHealingModelSystem(
    health_check_interval=60,
    recovery_strategy='rollback'
)

shms.monitor(model_endpoint)
```
