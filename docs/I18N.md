# i18n (12 languages)

AWEAI ships 12 language tables in `aweai/i18n.py` — no external dependency.

- English (primary), Հայերեն (Armenian), Русский, Français, Deutsch,
  Español, Italiano, Português, Türkçe, فارسی, 中文, 日本語

```python
from aweai.i18n import t, set_language
set_language("hy")
print(t("common.dashboard"))  # Վահանակ
```

```bash
aweai config set language=hy
aweai langs
```
