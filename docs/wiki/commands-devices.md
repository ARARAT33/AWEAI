# devices commands

Total commands: **10**

| Command | Description |
| --- | --- |
| `detect` | Detect this device: CPU/GPU/RAM/disk/platform. |
| `ssh` | Run a command on a remote machine via SSH. |
| `ssh-add` | Register a remote host in the device cluster. |
| `ssh-list` | List registered remote hosts. |
| `ssh-remove` | Remove a registered host. |
| `cluster-status` | Show cluster status of registered hosts (SSH probe). |
| `distributed` | Run distributed training (thread/torch backends). |
| `orchestrate` | Orchestrate local training workers (start/stop/status). |
| `lan` | Detect LAN IP addresses of this device. |
| `benchmark` | Quick CPU benchmark (prime computation rate). |
