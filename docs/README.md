# AWEAI Documentation

Welcome to the AWEAI documentation. AWEAI is an **AI model factory** — a
fully-automated toolkit that creates, trains, tunes and manages AI models
from scratch. It ships **no built-in AI** and has **no Hugging Face**
dependencies.
